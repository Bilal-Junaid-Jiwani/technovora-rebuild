# Agency inspiration — 20 digital/creative agencies survey
Researched 2026-09-26 (homepage + inner pages fetched). Patterns only, nothing copied.

## Per-agency notes

**Fantasy (fantasy.co)** — Full-bleed cinematic video hero, micro-kicker + sentence-case headline. Services as stark numbered index (01/02, oversized headings, no cards). Work index: one-line narrative insight BEFORE client name. Footer manifesto in huge type. Steal: insight-first work index. Avoid: video-everywhere.

**Active Theory (activetheory.net)** — Fully navigable 3D office, no hero banner. AI chat navigation. Steal: navigation-as-concept (one signature interaction). Avoid: 3D-lobby template — wrong energy for restrained B2B.

**Locomotive (locomotive.ca)** — Photographic hero, custom serif. Featured projects as fluid 110px serif titles separated by hard 2px rules, oversized index numbers, zero cards. Steal: hard-rule editorial structure. Avoid: emoji punctuation.

**Darkroom Engineering (darkroom.engineering)** — Dictionary-definition wordplay hero, lowercase. Work teaser: only 3 full-bleed projects + honest "want the full stack? head to Work". **Activity Log**: dated shipping changelog with redacted stealth work. Open-source tools section. Steal: Activity Log — dated receipts beat claims. Avoid: jokey voice.

**B-Reel** — Anti-hero plain text. "OUTPUT ARCHIVE" 1999–2024 as raw text listings. Steal: copy density as aesthetic, dated wins, verbatim third-party quotes. Avoid: too-raw minimalism.

**AKQA** — Typography-led giant SVG text-art hero. About as stacked statements + awards index grouped by award (trophy-wall data table). Steal: trophy-wall awards index. Avoid: manifesto-everything without substance.

**R/GA** — Sparse one-line hero. News-as-changelog (capability announcements as product launches). Steal: news-as-product-launches. Avoid: sparse hero needs real visuals behind it.

**Huge** — Full-bleed video under giant "Hello." 24+ client logos in long strip. "Never one and done" partnership blocks (image + one-line outcome, "14 years. Multiple businesses."). Services as numbered index 01–06 one-liners. Steal: numbered services index; partnership-over-project framing. Avoid: oversized logo strip.

**Work & Co (work.co)** — Typographic hero, no image, one plainspoken sentence + Fast Company quote as first proof. "Latest": single featured case, editorial style, not a grid. Footer as explicit sitemap list. Steal: single-featured-case + quote-as-first-proof. Avoid: near-total visual absence without reputation to back it.

**Instrument** — Statement headline + rotating project carousel (uniform 1:1 crops). Work index: "Client — one-line outcome — View Case Study" (outcome-led titles). Steal: uniform-crop grid + outcome-led titles — best B2B portfolio pattern. Avoid: carousel-as-hero.

**BASIC/DEPT** — Full-bleed dark video hero, circular "WATCH REEL" CTA. Horizontal-drag work carousel with giant circular "Drag" cursor, progress bar, index counter. Meta-bar rows above every section (1px rule + tiny uppercase label/value). ONE font, near-monochrome #F4F4F4/#252422, single azalea-pink accent. Steal: per-section meta-bar — editorial rhythm, zero decoration. Avoid: custom cursors, grain overlay.

**Hello Monday** — Full-bleed video hero, slab-serif headline, "days until Monday" counter. 3-col case grid: inactive cards dim to 20%, brighten on hover (focus-by-dimming). Steal: curtain page-wipe tinted with outgoing section's bg color. Avoid: blob menu, whimsical motion.

**ustwo** — Headline-led + editorial photography. Full-bleed flat-color brand panels per capability. Client feedback block "9.6/10, independent survey, June 2026" as typographic block. Steal: quantified testimonial as confident type block. Avoid: loud color-block sections.

**frog** — Video showreel hero. Case studies as long-form narrative chapters with principle-level subheads ("Form sets expectation"). Steal: chapter-structured case studies — portfolio as thought leadership. Avoid: consultancy blandness.

**COLLINS** — Typography-only hero ("Rewrite your worth."). "Programs": 11 services as bold name + punchy tagline pairs ("Reposition — Don't Become the Best. Become the Only.") in stacked list; writing IS the visual. Case template: client name huge → "Augments" → "Impact" (H3+paragraph) → "Press" links. Steal: services-as-tagline list; case-study template. Avoid: typography-only hero needs genuinely great copy.

**Koto** — Minimal typographic hero. Uniform case-study system: one big visual, one idea-line, identical chrome. Per-office contact blocks as rhythmic grid. Steal: uniform case system. Avoid: duplicated city blocks — dead scroll weight.

**Studio Output** — Statement typographic hero. Work index: each case built around one named concept. News as studio journal. Steal: one named concept per case study. Avoid: maximalist expressive register.

**Cuberto** — Full-viewport statement headline, typography-only, black-on-white. Five service cards each pairing outcome description with dedicated visual panel (product-demo feel). Tight monochrome logo wall. Metric-framed FAQ answering technical objections. Steal: service-card-plus-visual-panel; objection-handling FAQ. Avoid: custom cursors, preloaders.

**Clay (clay.global)** — Centered typographic hero, no video above fold; most enterprise-SaaS of the set. Six stacked capability bands, each with image panel + 2-line description (services as product tour). Honest FAQ (pricing models, timezones, startup vs enterprise). Steal: stacked capability bands + FAQ-as-objection-handling. Avoid: FAQ too long (keep 4–5).

**Ramotion** — Video hero naming buyer + outcome in one sentence. Logo wall where EACH logo gets one-line outcome ("We crafted Stripe's iconography…") — logo wall with receipts. Case cards lead with hard metrics. Steal: logo-wall-with-outcomes — single best B2B trust pattern found. Avoid: 11-testimonial carousel; keyword-stuffed word cloud.

## Builder's shortlist (ranked for Linear/Vercel/Stripe/monday restraint)
1. Ramotion's logo-wall-with-outcomes
2. Instrument's uniform-crop grid + outcome-led titles
3. BASIC/DEPT's per-section meta-bar
4. COLLINS' services-as-tagline list
5. Darkroom's Activity Log (shipping changelog)
6. Work & Co's single-featured-case "Latest" + quote-as-first-proof
7. Clay/Cuberto's objection-handling FAQ (4–5 Qs)
8. frog's chapter-structured case studies
9. Huge's numbered services index (01–06)
10. Fantasy's insight-first work index

## Universal anti-patterns
Fake/generic logos without outcomes; custom cursors, preloaders, blob menus, film grain; auto-rotating hero carousels; manifesto copy without substance; video-everywhere; emoji punctuation; over-long FAQ / keyword stuffing.
